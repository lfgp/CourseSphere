# CourseSphere

CourseSphere is a web application that helps students find the best courses for them to take.

## Atenção ##
A branch analisys foi criada para avaliação e melhoria do código para o desafio a fim de preservar e comparar o código original, seguindo as boas práticas de programação, para caso precise retornar a uma versão estável. O CI será ativado nessa branch principal e toda configuração veio da branch de análise, para testes externos.
